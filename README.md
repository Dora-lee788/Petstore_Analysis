# Анализ результатов тестирования Petstore API

Рефакторинг 38 тестовых сценариев REST API Petstore с использованием xUnit и NUnit.

API: https://petstore.swagger.io/v2

## Структура
- Petstore.XUnit — 38 тестов на xUnit
- Petstore.NUnit — 38 тестов на NUnit
- Analysis1.md — количественный анализ
- Analysis2.md — качественный анализ
- ControlQuestions.md — контрольные вопросы
- Screenshots — скриншоты запусков

## Запуск
Из корня решения:
```powershell
dotnet test Petstore.XUnit
dotnet test Petstore.NUnit
```
Результаты и время выполнения для Analysis1.md заполнить по фактическим запускам. Скриншоты добавить в Screenshots.
