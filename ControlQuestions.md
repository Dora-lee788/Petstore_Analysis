# Контрольные вопросы

## 1. Для чего предназначены модульные тесты?
Модульные тесты проверяют отдельные части программного кода, помогают обнаруживать ошибки на ранних этапах, подтверждают ожидаемое поведение и упрощают дальнейшие изменения.

## 2. Чем отличается NUnit от xUnit?
NUnit использует атрибуты, например `[Test]`, `[SetUp]` и `[TestCase]`. xUnit использует `[Fact]`, `[Theory]`, `[InlineData]`, а подготовка экземпляна тестового класса обычно выполняется через конструктор.

## 3. Что такое параметризация тестов?
Параметризация позволяет запускать один тест с несколькими наборами входных данных, не дублируя тестовый метод.

## 4. Для чего используются фикстуры?
Фикстуры подготавливают необходимые объекты и условия для тестов, а также помогают организовать очистку после выполнения.

## 5. Зачем тестировать работу репозиториев?
Проверка репозиториев подтверждает корректность сохранения, получения, изменения и удаления данных, а также взаимодействия с источником данных.

## 6. Как выполняется запуск тестов в .NET? (укажите IDE)
В Visual Studio тесты можно запускать через Test Explorer, выбрав Run All или запустив отдельные тесты. Также тесты запускаются командой `dotnet test` в терминале.

## 7. Что общего между pytest и xUnit?
Оба фреймворка позволяют автоматизировать тестирование, организовывать тестовые сценарии, проверять ожидаемые результаты, запускать тесты и использовать параметризацию.

## 8. В чем преимущества pytest?
pytest имеет простой синтаксис, подробные сообщения при ошибках, удобную параметризацию, фикстуры и расширяемость с помощью плагинов.

## 9. Для каких задач может быть интересен Expecto?
Expecto предназначен для тестирования приложений на F#. Он поддерживает организацию тестов, проверки условий и работу в функциональном стиле.
