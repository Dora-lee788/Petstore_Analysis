# Контрольные вопросы

## 1. Для чего предназначены модульные тесты?

Модульные тесты проверяют отдельные части программы, помогают находить ошибки и убеждаться, что код работает правильно.

## 2. Чем отличается NUnit от xUnit?

NUnit использует атрибуты `[Test]`, `[SetUp]`, `[TearDown]`. В xUnit применяются `[Fact]` и `[Theory]`, а подготовка тестового класса выполняется через конструктор.

## 3. Что такое параметризация тестов?

Параметризация позволяет запускать один тест с разными входными данными без создания отдельных тестовых методов для каждого случая.

## 4. Для чего используются фикстуры?

Фикстуры нужны для подготовки объектов и условий, необходимых тестам, а также для выполнения очистки после их завершения.

## 5. Зачем тестировать работу репозиториев?

Тестирование репозиториев позволяет проверить создание, получение, изменение и удаление данных, а также корректность взаимодействия с базой данных.

## 6. Как выполняется запуск тестов в .NET? Укажите IDE.

В Visual Studio тесты можно запускать через Test Explorer, используя Run All или запуск отдельных тестов. Также можно использовать команду `dotnet test` в терминале.

## 7. Что общего между pytest и xUnit?

Оба фреймворка предназначены для автоматизации тестирования. Они позволяют создавать тестовые сценарии, проверять ожидаемые результаты и повторно запускать тесты.

## 8. В чем преимущества pytest?

pytest отличается простым синтаксисом, удобными фикстурами, параметризацией, подробными сообщениями об ошибках и поддержкой расширений.

## 9. Для каких задач может быть интересен Expecto?

Expecto предназначен для тестирования приложений на языке F#. Он позволяет организовывать тесты, проверять ожидаемые результаты и использовать функциональный подход.
